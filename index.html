三角関数のグラフ

操作ガイド
  1. 単位円の点をドラッグするか、有名角ボタンを押して、動径を動かす。
  2. 点Pの座標と sin・cos・tan の値を確認する。
  3. 下の問題を読み、答えを選んで「答え合わせ」を押す。考えてから「答えと解説」を見よう。
操作ガイド

単位円の点を動かして、三角関数のグラフを作ってみよう！

  1. 円周上の点をドラッグする。
  2. 点の角度と三角関数の値を確認する。
  3. 点を動かすと、グラフが描かれる。
  4. 1周以上動かして、グラフの繰り返しを観察する。
操作ガイド
  1. 薄い破線が変化前 y = f(θ)、濃い実線が変化後のグラフ。
  2. 下の4つのスライダーを動かして、グラフがどう変わるか調べる。
  3. 周期を変えると、山から次の山までの距離（矢印）が変わる。

b が大きいほど周期は短くなる（負なら左右反転）。

c > 0 で右へ、c < 0 で左へ動く（θ − c）。

d > 0 で上へ、d < 0 で下へ動く。
